# Circom Working Directory

This directory serves as the working directory for the RISC Zero → Circom → Gnark proof conversion workflow.

## Purpose

The PPEM system uses a multi-proof architecture:
1. **RISC Zero** computes auction proofs 
2. **Circom** converts and verifies RISC Zero proofs
3. **Gnark** verifies circom proofs recursively in the main protocol

## Workflow

1. RISC Zero generates `input.json` and copies it here
2. `populate_circom_data.sh` runs the circom proof generation
3. Generated proofs are placed in `circom_data/`
4. Main PPEM protocol loads and verifies the proofs

## Files

- `populate_circom_data.sh` - Circom proof generation script
- `input.json` - Generated by RISC Zero (runtime)
- `circom_data/` - Generated proof files (runtime)

## Note

The actual circom conversion source code is in `internal/pkg/circom/` and `cmd/circom-gro/`.
This directory is just the working space for the proof generation workflow.
